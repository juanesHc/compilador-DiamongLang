¿Por qué la línea 11 de mi código es un error? Dice que no puedo asignar una cadena a un entero.
Tú • 10:42 AM

En la línea 11 tienes entero x <- "hola".

La variable x está declarada como entero, pero el valor a la derecha es la cadena "hola". DiamondLang tiene tipado estático estricto y no realiza conversiones automáticas entre cadenas y enteros.

Opciones: Tienes dos opciones: cambiar la declaración a cadena x <- "hola" o asignar un valor entero como entero x <- 0.

¿Cuál es la diferencia entre la Regla 3 y la Regla 4 del compilador?
  • Regla 3 (TYPE_ASSIGNMENT): Valida que el tipo del lado derecho de una asignación sea compatible con el tipo de la variable de destino.
  • Regla 4 (TYPE_CONDITION): Requiere que la condición de un si o mientras sea estrictamente de tipo booleano, sin promociones numéricas.
