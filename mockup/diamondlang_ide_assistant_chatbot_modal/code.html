On line 11 you have entero x <- "hola".

The variable x is declared as entero (integer), but the value on the right side is the string "hola". The DiamondLang compiler requires strict type matching for all assignments.

info Fix: Change "hola" to an integer or redeclare x as 'cadena'.

What's the difference between Rule 3 and Rule 4 of the compiler?
  • Rule 3 (TYPE_ASSIGNMENT): Validates that the type of the right-hand side expression matches the declared type of the target variable.
  • Rule 4 (TYPE_CONDITION): Requires that the condition of si (if) and mientras (while) is strictly of boolean type.
